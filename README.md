## Project Description
A C# Console Application that acts as a virtual assistant to educate users on cybersecurity topics in a conversational manner. The bot provides practical advice on password safety, phishing, and safe browsing.

## Features
- Voice greeting (VoiceGreeting class included; audio playback disabled due to local SDK issue)
- ASCII art header/logo displayed on launch
- Personalised greeting using the user's name
- Password safety responses
- Phishing responses
- Safe browsing responses
- Input validation for blank or unsupported questions
- Coloured console interface with a typing effect
- Conversation loop that continues until the user types 'exit'
- Proper object-oriented structure using 6 separate classes

## How to Run
1. Clone/download the repository.
2. Open the solution in Visual Studio 2022.
3. Build the project (Ctrl + Shift + B).
4. Press Ctrl + F5 to run.
5. Type your name, then ask about passwords, phishing, safe browsing, or my purpose.
